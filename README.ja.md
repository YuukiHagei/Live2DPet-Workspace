# Live2DPet Workspace — AI デスクトップペットコンパニオン

**[中文](README.md)** | **[English](README.en.md)** | **日本語**

> 本プロジェクトの宣伝名は **Live2DPet Workspace** です。実行ファイルとユーザーデータディレクトリは引き続き元の名前 `Live2DPet` / `live2dpet` を使用します。使用には影響ありません。

> 本プロジェクトは [x380kkm/Live2DPet](https://github.com/x380kkm/Live2DPet) のフォークであり、MIT ライセンスに従います。

**AI 会話、スケジュール管理、フラッシュカード、ポモドーロタイマー、カウントダウンタイマー、タスクエージェント、クラウド同期** を Live2D デスクトップペットに詰め込んだオープンソースデスクトップアプリです。

## コア機能

### 1. 会話と記憶

- **自然対話** — OpenAI 互換 API すべてに対応（DeepSeek、OpenRouter、Grok、Ollama など）
- **ロールプレイ** — キャラクターカードで名前、身分、性格、呼び方、シナリオ、厳格ルールを定義
- **ユーザーを記憶** — 「ユーザープロファイル」（名前、身分、目標、好み、背景）を自動抽出、会話を跨いで保持
- **環境観察** — アクティブウィンドウのタイトルとスクリーンショットで AI が作業内容を把握
- **音声合成** — VOICEVOX 統合、日本語音声で読み上げ（中国語は自動翻訳）
- **一緒にいた日数** — 初回起動からカウント、AI が自然に「どのくらい一緒にいるか」に触れられる
- **会話メモリ** — 直近 12 件の会話を保持、日付が変わるとプロンプトに日付マーカーを挿入
- **Agent 履歴要約** — 20 件のスライディングウィンドウ + 古いメッセージを要約に圧縮

### 2. 3 つの会話モード

チャットボックスの左側にある切替ボタンで、アイコンが循環します：

| アイコン | モード | 動作 |
| :--- | :--- | :--- |
| 💬 | 通常会話 | 日常的な雑談、AI が自発的に話す |
| 🤖 | Agent モード | ツールを呼び出してタスク実行（ファイル操作、TODO、フラッシュカードなど） |
| 📋 | プランモード | AI が先に実行計画を提示、ユーザー承認後に実行 |

### 3. Agent 内蔵ツール

自然言語で話しかけるだけで呼び出せます：

**ファイル系（デフォルト許可）**
- ファイル読込、ディレクトリー覧、再帰的ディレクトリー覧
- ファイル名検索（`*.js` ワイルドカード対応）
- 内容検索（正規表現対応）

**タスク系（デフォルト許可）**
- TODO: 追加、一覧、完了、更新、削除
- スケジュール：追加、一覧、更新、削除
- リマインダー：追加、一覧、削除（毎日/毎週リピート対応）
- フラッシュカード：追加、更新、一覧、レビュー、削除、統計
- タイマー：カウントダウン/カウントアップ作成、一覧、一時停止、再開、削除
- ポモドーロ：多段階の作業/休憩サイクル開始

**機密系（デフォルト確認）**
- ファイル書込、URL オープン

各ツールの権限は **設定 → Agent ツール権限** で `allow`（直接実行）、`ask`（毎回確認）、`deny`（禁止）に変更可能。

### 4. MCP ツール拡張

内蔵ツールに加えて、任意の MCP サーバーを接続可能：
- **設定 → MCP → 「+ サーバー追加」**
- 例: `@modelcontextprotocol/server-filesystem`、`mcp-server-git`
- 複数サーバー対応、同名ツールは自動でプレフィックス付与

### 5. カレンダー / スケジュール / リマインダー / TODO

ペットを右クリック → **ツール → カレンダー**：

- **月表示**、スケジュールがある日にマーカー表示
- **複数日にまたがるスケジュール** は色付き帯で表示
- 日付をクリックで **スケジュール、TODO、リマインダー、フラッシュカード** を表示
- カレンダー上で直接、スケジュール、TODO、リマインダーを作成/編集/削除
- **リマインダーの状態**：
  - 発動後：「✓ 通知済み」（取り消し線）
  - 30 分以上過ぎた場合：「⚠️ 見逃し」
- フラッシュカードの **次回復習日** を切り替え

### 6. フラッシュカード（SM-2）

ペットを右クリック → **ツール → 復習カード**：

- カードには表（質問）と裏（答え）、科目とタグを設定可能
- Anki と同じ **SM-2 間隔反復アルゴリズム**
- 4 段階評価：忘れた / 難しい / 覚えた / 簡単
- 独立ウィンドウ、キーボードショートカット対応：Space で裏返し、1/2/3/4 で評価、ESC で閉じる
- 編集、削除、新規作成、検索、科目/タグでフィルター

### 7. タイマー / ポモドーロ / フローティングバブル

ペットを右クリック → **ツール → カウントダウン / タイマー**：

**カウントダウン**
- カスタム名と時長（時/分/秒）
- クイックプリセット：1 分 / 3 分 / 5 分 / 25 分
- カスタム通知メッセージ（既定値は **設定 → タイマー既定の通知メッセージ** で編集可能）
- 完了時にカレンダーへ自動書き込み

**カウントアップ**
- 目標時長なし、手動で停止
- 停止後「今回の所要時間 X 分 Y 秒」を報告
- 完了時にカレンダーへ自動書き込み

**共通操作**
- 一時停止 / 再開
- 完了後「🔄 もう一度」で時長のみ変更、名前は保持
- 複数タイマーの並行実行
- `{name}` などのキャラクターカードテンプレート対応

**ポモドーロ**
- ワンクリックで定番の 25/5 サイクル
- クイックプリセット：25/5、50/10、90/20
- 作業 / 休憩 / 長休憩 / 長休憩までのラウンド数 / 総ラウンド数をカスタマイズ可能
- フェーズ切り替えを自動通知、手動介入不要
- **ポモドーロ全体の終了時** にのみカレンダーに 1 件のサマリーを書き込み（フェーズごとではない）

**タイマーフローティングバブル**
- 独立した透明ウィンドウ、画面の任意の位置にドラッグ可能（位置は永続化）
- 実行中の上位 3 タイマーの残り時間を表示
- ホバーで **⏸ 一時停止 / ▶ 再開 / × 停止** ボタンを表示
- タイマーがない時は **自動的に非表示**、ある時は **自動的に表示**
- ユーザーが手動で閉じた場合は自動的に再表示されない（すべてのタイマーが削除されるまで）

### 8. デイリーブリーフ / 週報・月報

**朝のブリーフ（デフォルト 7:30 発動）**
- 天気、気温、UV 指数
- 気温に応じた服装アドバイス、UV に応じた日焼け対策
- 今日のスケジュール、リマインダー、期限付き TODO

**夜のブリーフ（デフォルト 22:00 発動）**
- 今日完了したもの、まだ残っているもの、明日のスケジュールとリマインダー

**週報 / 月報**
- 週報は日曜 21:00、月報は月末 21:00
- TODO 完了率、スケジュール数、復習回数、科目別の誤答率

すべてのブリーフはキャラクターロ調で生成、データを機械的に読み上げません。

### 9. ユーザープロファイルと観察データ

ペットを右クリック → **記憶**：

- **Agent 履歴を表示** — すべての Agent モード会話のスライディングウィンドウ + 要約
- **観察データを表示** — よく連絡する人（回数順、トピックタグ付き）、最近のチャット記録（**ウィンドウタイトルのみ**）
- **ユーザープロファイル** — AI が抽出したあなたに関する長期情報（名前、身分、目標、好み、背景）、リセット可能

### 10. クラウド同期

設定 → **クラウド同期**：

2 つのプロバイダから 1 つ選択：

**GitHub Gist**（推奨）
- 完全無料
- **プライベート Gist** と **Personal Access Token**（`gist` 権限のみ）が必要
- `https://api.github.com/gists` 経由

**Nutstore WebDAV**
- Nutstore アカウント + **アプリパスワード**（ログインパスワードではない）が必要
- `https://dav.jianguoyun.com/dav/` 経由

**機能**
- **自動同期**：データ変更後 5 秒で自動アップロード
- **終了前フラッシュ**：終了前に同期完了を保証
- **起動時サイレント同期**：起動後 8 秒で実行
- **競合検出**：ローカルとクラウド両方が変更された場合にポップアップ、**ローカル保持 / クラウド保持 / マージ** を選択
- **スマートマージ**：`id` + `updatedAt` で配列をマージ、チャットはタイムスタンプで重複排除
- **危険な上書き保護**：ローカルが空でクラウドが非空（またはその逆）の場合はスキップ、誤った消去を防止
- **手動リセット**：偽の競合を修正

同期されるデータ：TODO、スケジュール、リマインダー、フラッシュカード、会話メモリ、Agent 履歴、ユーザープロファイル、観察ログ、タイマー、一緒にいた日数など。

### 11. モバイル PWA

iPhone/Android ブラウザでデプロイ先 URL を開くと、独立したアプリとして使用可能：

- **データソース** — 同じ Gist から読み込み
- **機能** — TODO、スケジュール、フラッシュカードの閲覧、作成/編集/削除、カード復習
- **AI チャット** — 独立した API Key 設定、ユーザープロファイルと観察ログを注入
- **ホーム画面に追加** — iOS Safari の共有 → ホーム画面に追加で全画面表示

PWA デプロイセクション参照（オプション、初回のみ）。

## クイックスタート

### 1. API 設定

設定パネル → **設定** タブ → API アドレス、キー、モデル名を入力。OpenAI 形式の API エンドポイントすべてに対応。

スクリーンショット認識のため Vision 対応モデルを推奨：
- コスパ：Grok シリーズ / DeepSeek
- ミドル：GPT-o3 / GPT-5.1
- 高品質：Gemini 3 Pro Preview

翻訳 API（TTS 日本語翻訳用）：OpenRouter `x-ai/grok-4-fast`

### 2. Live2D モデルのインポート

**モデル** タブ → 「モデルフォルダを選択」（`.model.json` または `.model3.json` を含む）。パラメータ、表情、モーションを自動スキャン。

画像フォルダもキャラクター画像として使用可能。

モデルがない場合は Live2D 公式サンプルから無料モデルをダウンロード。

### 3. VOICEVOX 音声合成の設定（オプション）

1. **TTS** タブ → VOICEVOX コンポーネントをインストール（Core + ONNX Runtime + Open JTalk 辞書）
2. VVM 音声モデルをダウンロード
3. 「保存して再起動」をクリック
4. スピーカー、スタイル、その他パラメータを調整

<details>
<summary>VOICEVOX の手動インストール</summary>

インストール先: `C:\Users\ユーザー名\AppData\Roaming\live2dpet\voicevox_core`

| コンポーネント | 必須 | ダウンロード |
| :--- | :--- | :--- |
| VOICEVOX Core | はい | `voicevox_core-windows-x64-0.16.3.zip` |
| ONNX Runtime (CPU) | はい | `voicevox_onnxruntime-win-x64-1.17.3.tgz` |
| ONNX Runtime (GPU) | いいえ | `voicevox_onnxruntime-win-x64-dml-1.17.3.tgz` |
| Open JTalk 辞書 | はい | `open_jtalk_dic_utf_8-1.11.tar.gz` |
| デフォルト音声モデル | はい | `0.vvm` |
| その他モデル | いいえ | `*.vvm` |

</details>

### 4. キャラクターのカスタマイズ

**Prompt** タブ → 新しいキャラクターカードを作成。名前、性格、ルールを編集。テンプレート変数 `{{petName}}`、`{{userIdentity}}` に対応。

### 5. ペットを起動

設定画面下部の **「ペットを起動」** をクリック。

- ドラッグで位置移動
- 目がマウスカーソルを追従（Live2D モード）
- AI が定期的にスクリーンショットを撮り、吹き出しで会話
- ペットを右クリックでメニュー

## サードパーティライセンスとコンプライアンス

### Live2D Cubism Core

Live2D のライセンス制限により、本プロジェクトは `live2dcubismcore.min.js` および `cubism4.min.js` を **含みません**。
ソースから初めて実行する場合、または再クローン後は、[Live2D 公式サイト](https://www.live2d.com/) から SDK をダウンロードし、`live2dcubismcore.min.js` を `libs/` ディレクトリに配置してください。

### VOICEVOX

本プロジェクトは VOICEVOX を統合しています。[VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/) を遵守し、`VOICEVOX: キャラ名` を表記してください。

**注意**：ライセンス遵守のため、本リポジトリには VOICEVOX Core のビルド済みバイナリファイルは含まれていません。
[VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/) から Core コンポーネントをダウンロードし、解凍して `voicevox_core/` フォルダに配置してください。

### その他の依存関係

詳細は `THIRD_PARTY_LICENSES.md` を参照してください。

## トラブルシューティング

コンソールログを有効にして起動：

```bash
"フォルダパス\Live2DPet.exe" --enable-logging 2>&1
```

またはソースから：

```bash
node launch.js
```

問題発生時のログを記録し、Issue 提出時に添付してください。

**よくある問題**：

- **データが「消えた」** — まず `data/.backup/` を確認、クラウド同期は上書き前にバックアップします
- **クラウド同期の競合** — 設定 → クラウド同期 → 「同期状態をリセット」をクリック
- **MCP ツールが起動しない** — 内蔵ツールのコマンドが `{electron}`、args が `{mcpServer}/mcp-server.js` であることを確認
- **TTS が無音** — `voicevox_core/` ディレクトリと VVM モデルが完全か確認

## 既知の問題

- スクリーンショット関連の warning は無視して問題ありません
- VVM 音声モデルの読み取りエラー：`voicevox_core` の破損ファイルを削除して再ダウンロード
- GPU 加速を有効にすると TTS 読み取りに失敗 — CPU のみ使用してください
- 長文（60 字超）は短縮読み上げ：VOICEVOX は CPU モードで長文が不安定
- 30 分以上過ぎたリマインダーは自動的に「見逃し」に（時刻を編集でリセット）
- デスクトップとモバイルで同じレコードを編集すると競合ダイアログが出る可能性あり

- **Node.js >= 18**（ソースから実行する場合）
- **OpenAI 互換 API キー**
- **VOICEVOX Core**（オプション、音声合成用）
- **GitHub Gist または Nutstore**（オプション、クラウド同期用）
