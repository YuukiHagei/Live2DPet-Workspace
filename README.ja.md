# Live2DPet Workspace — AI デスクトップペットコンパニオン
> 注：本プロジェクトの宣伝名は **Live2DPet Workspace** です。実行ファイルとユーザーデータディレクトリは引き続き元の名前 `Live2DPet` / `live2dpet` を使用します。使用には影響ありません。
**[中文](README.md)** | **[English](README.en.md)** | **日本語**

> 本プロジェクトは [x380kkm/Live2DPet](https://github.com/x380kkm/Live2DPet) のフォークであり、MIT ライセンスに従います。

AI 会話、スケジュール管理、フラッシュカード、タスクエージェントを Live2D デスクトップペットに詰め込んだオープンソースデスクトップアプリです。

---

## コア機能

### 1. 会話と記憶を持つペット
- **自然対話** — OpenAI 互換 API すべてに対応（DeepSeek、OpenRouter、Grok、Ollama など）
- **ロールプレイ** — キャラクターカードで名前、身分、性格、呼び方、シナリオ、厳格ルールを定義
- **ユーザーを記憶** — 「ユーザープロファイル」（名前、身分、目標、好み）を自動抽出、会話を跨いで保持
- **環境観察** — アクティブウィンドウのタイトルとスクリーンショットで AI が作業内容を把握
- **音声合成** — VOICEVOX 統合、日本語音声で読み上げ（中国語は自動翻訳）
- **一緒にいた日数** — 初回起動からカウント、AI が自然に「どのくらい一緒にいるか」に触れられる

### 2. 3 つの会話モード
チャットボックスの左側にある切替ボタンで、アイコンが循環します：

| アイコン | モード | 動作 |
| :--- | :--- | :--- |
| 💬 | 通常会話 | 日常的な雑談、AI が自発的に話す |
| 🤖 | Agent モード | ツールを呼び出してタスク実行（ファイル操作、TODO、フラッシュカードなど） |
| 📋 | プランモード | AI が先に実行計画を提示、ユーザー承認後に実行 |

### 3. Agent 内蔵ツール
自然言語で話しかけるだけで呼び出せます：

**ファイル系（デフォルト許可）**
- ファイル読込、ディレクトリー覧、再帰的ディレクトリー覧
- ファイル名検索（`*.js` ワイルドカード対応）
- 内容検索（正規表現対応）

**タスク系（デフォルト許可）**
- TODO: 追加、一覧、完了、更新、削除
- スケジュール：追加、一覧、更新、削除
- リマインダー：追加、一覧、削除（毎日/毎週リピート対応）
- フラッシュカード：追加、更新、一覧、レビュー、削除、統計

**機密系（デフォルト確認）**
- ファイル書込、URL オープン

各ツールの権限は **設定 → Agent ツール権限** で `allow`（直接実行）、`ask`（毎回確認）、`deny`（禁止）に変更可能。

### 4. MCP ツール拡張
内蔵ツールに加えて、任意の MCP サーバーを接続可能：
- **設定 → MCP → 「+ サーバー追加」**
- 例: `@modelcontextprotocol/server-filesystem`、`mcp-server-git`
- 複数サーバー対応、同名ツールは自動でプレフィックス付与

### 5. カレンダー + TODO 可視化
ペットを右クリック →「カレンダー」：
- 月表示、スケジュールがある日にマーカー表示
- 日付をクリックでその日のスケジュールと TODO を表示
- カレンダー上で直接スケジュールを作成/編集/削除

### 6. フラッシュカード（SM-2 アルゴリズム）
ペットを右クリック →「復習カード」：
- カードには表（質問）と裏（答え）、科目とタグを設定可能
- Anki と同じ SM-2 間隔反復アルゴリズム
- 4 段階評価：忘れた / 難しい / 覚えた / 簡単
- 評価に応じて次回復習日を自動計算（EF が高いほど間隔が長い）
- 「📋 全カード」で閲覧、検索、編集、削除、新規作成
- 独立ウィンドウ、キーボードショートカット対応：Space で裏返し、1/2/3/4 で評価、ESC で閉じる

### 7. デイリープリーフ + 週報/月報
**朝のブリーフ（デフォルト 7:30 発動）**
- 天気、気温、UV 指数
- 気温に応じた服装アドバイス、UV に応じた日焼け対策
- 今日のスケジュール、リマインダー、期限付き TODO

**夜のブリーフ（デフォルト 22:00 発動）**
- 今日完了したもの
- まだ残っているもの
- 明日のスケジュールとリマインダー

**週報 / 月報**
- 週報は日曜 21:00、月報は月末 21:00
- TODO 完了率、スケジュール数、復習回数、科目別の誤答率

すべてのブリーフはキャラクターロ調で生成、データを機械的に読み上げません。

### 8. 観察データの可視化
ペットを右クリック →「観察データを表示」：
- よく連絡する人（回数順、トピックタグ付き）
- 最近のチャット記録（ウィンドウタイトルのみ、チャット内容は保存しない）

## 使い方

### 1. API 設定
設定パネルの「API 設定」タブに API アドレス、キー、モデル名を入力。OpenAI 形式の API エンドポイントすべてに対応。

スクリーンショット認識のため Vision 対応モデルを推奨：
- コスパ：Grok シリーズ / DeepSeek
- ミドル: GPT-o3 / GPT-5.1
- 高品質: Gemini 3 Pro Preview

翻訳 API（TTS 日本語翻訳用）：
- OpenRouter `x-ai/grok-4-fast`

### 2. Live2D モデルのインポート
「モデル」タブで「モデルフォルダを選択」をクリック、`.model.json` または `.model3.json` を含むディレクトリを選択。システムが自動でモデルパラメータ、表情、モーショングループをスキャン。

画像フォルダもキャラクター画像として使用可能。

Live2D モデルがない場合は Live2D 公式サンプルから無料モデルをダウンロード。

### 3. VOICEVOX 音声合成の設定（オプション）
1. 「TTS」タブで VOICEVOX コンポーネントをインストール（Core + ONNX Runtime + Open JTalk 辞書）
2. VVM 音声モデルを選択してダウンロード
3. 「保存して再起動」をクリック
4. スピーカー、スタイル、その他パラメータを調整

<details>
<summary>VOICEVOX の手動インストール</summary>

インストール先: `C:\Users\ユーザー名\AppData\Roaming\live2dpet\voicevox_core`

| コンポーネント | 必須 | ダウンロード |
| :--- | :--- | :--- |
| VOICEVOX Core | はい | `voicevox_core-windows-x64-0.16.3.zip` |
| ONNX Runtime (CPU) | はい | `voicevox_onnxruntime-win-x64-1.17.3.tgz` |
| ONNX Runtime (GPU) | いいえ | `voicevox_onnxruntime-win-x64-dml-1.17.3.tgz` |
| Open JTalk 辞書 | はい | `open_jtalk_dic_utf_8-1.11.tar.gz` |
| デフォルト音声モデル | はい | `0.vvm` |
| その他モデル | いいえ | `*.vvm` |

</details>

### 4. キャラクターのカスタマイズ
「キャラクター」タブで新しいキャラクターカードを作成。テンプレート変数 `{{petName}}`、`{{userIdentity}}` に対応。

### 5. ペットを起動
設定画面下部の「ペットを起動」をクリック。キャラクターがデスクトップ右下に透明ウィンドウで表示されます。
- ドラッグで位置移動
- 目がマウスカーソルを追従（Live2D モード）
- AI が定期的にスクリーンショットを撮り、吹き出して会話
- ペットを右クリックでメニュー：サイズ/位置、会話開始、履歴、復習カード、カレンダー、設定など

## 会話例

**日常**
```text
今日はちょっと疲れた
研究テーマを考えて
最近誰とよく話してる？
```

**TODO・スケジュール**
```text
明日牛乳を買うのを忘れないで
明日の午後３時に指導教員とミーティング
今週の予定は？
牛乳買った
「牛乳を買う」を明後日に変更して
```

**リマインダー**
```text
毎日 23:30 に寝るようにリマインドして
10 分後に鍋を見るのをリマインドして
```

**フラッシュカード**
```text
「カントの三大批判」をカード追加、科目は西洋哲学史
今日の復習は何？
復習開始
（AI の出題に答えて）……忘れた
カードは何枚ある？
```

**Agent タスク（🤖 モード）**
```text
src ディレクトリの全ファイルを一覧
プロジェクト内で「TODO」を検索
package.json を読んで
```

**プランモード（📋）**
```text
このプロジェクトのログシステムをリファクタリングして
（AIが計画を提示、「承認」をクリックしてから実行）
```

## データ保存

すべてローカル保存、サーバーには送信しません：

```text
C:\Users\ユーザー名\AppData\Roaming\live2dpet\
├── config.json         設定（APIキー、TTSパラメータなど）
├── data/               構造化データ
│   ├── todos.json       TODO
│   ├── schedules.json   スケジュール
│   ├── reminders.json   リマインダー
│   ├── flashcards.json  フラッシュカード
│   ├── companion.json   一緒にいた日数
│   ├── daily-brief.json ブリーフ状態
│   ├── report-state.json レポート状態
│   └── reports/         週報/月報の履歴
└── voicevox_core/      VOICEVOX コンポーネントとモデル
```

テキストエディタで直接編集可能。

## 機能

- **Live2D デスクトップキャラクター** — 透明フレームレスウィンドウ、常に最前面、目がカーソル追従
- **画像モデル** — 画像フォルダをキャラクターとして使用、待機/会話/表情で分類
- **AI 視覚認識** — 定期スクリーンショット + アクティブウィンドウ検出
- **インタラクション** — クリック/タッチ/ドラッグ/スワイプ/リサイズ、AI コンテキストに注入
- **キーフレーム視覚メモリ** — VLM が代表的なキーフレームを選択
- **VOICEVOX 音声** — ローカル日本語 TTS、自動翻訳、ワンクリックセットアップ
- **感情システム** — AI 駆動の表情/モーション選択
- **Agent モード** — 3 つの会話モード + 20 以上の内蔵ツール + MCP 拡張
- **カレンダー・TODO** — 自然言語管理 + カレンダー表示
- **フラッシュカード** — SM-2 アルゴリズム + 独立復習ウィンドウ
- **デイリーブリーフ** — 天気、服装、日焼け対策アドバイス
- **週報/月報** — 学習進捗サマリー
- **マルチキャラクター** — JSON テンプレート、切替可能

## 注意事項

- **プライバシー**：スクリーンショットは設定した API にのみ送信、ディスクには保存されません
- **API 料金**：Vision モデルの呼び出しには料金が発生、検出間隔を適切に設定
- **VOICEVOX**：音声使用時は `VOICEVOX:キャラ名` のクレジット表記が必要
- **複数インスタンスを同時に起動しない**：ファイルロックを奪い合い、データ不整合の原因になります

## サードパーティライセンスとコンプライアンス

### Live2D Cubism Core
Live2D のライセンス制限により、本プロジェクトは `live2dcubismcore.min.js` および `cubism4.min.js` を**含みません**。
ソースから初めて実行する場合、または再クローン後は、[Live2D 公式サイト](https://www.live2d.com/) から SDK をダウンロードし、`live2dcubismcore.min.js` を `libs/` ディレクトリに配置してください。

### VOICEVOX
本プロジェクトは VOICEVOX を統合しています。[VOICEVOX 利用規約](https://voicevox.hiroshiba.jp/term/) を遵守し、`VOICEVOX: キャラ名` を表記してください。

### その他の依存関係
詳細は `THIRD_PARTY_LICENSES.md` を参照してください。

## トラブルシューティング

問題発生時、コマンドプロンプト（cmd）で以下を実行してコンソールログを有効に：

```bash
"フォルダパス\Live2DPet.exe" --enable-logging 2>&1
```

問題発生時のログ出力を記録し、Issue 提出時に添付してください。

## 既知の問題

- スクリーンショット関連の warning は無視して問題ありません
- VVM 音声モデルの読み取りエラー：`voicevox_core` で破損ファイルを削除して再ダウンロード
- GPU 加速を有効にすると TTS 読み取りに失敗します — CPU のみ使用してください
- 長文（60 字超）は TTS をスキップ：VOICEVOX は CPU モードで長文が不安定なため、吹き出しのみ表示

## 動作環境

- Windows 10/11
- Node.js >= 18（ソースから実行する場合）
- OpenAI 互換 API キー
- VOICEVOX Core（オプション、音声合成用）
**注意**：ライセンス遵守のため、本リポジトリには VOICEVOX Core のビルド済みバイナリファイルは含まれていません。
以下の手順に従ってご自身で取得してください：
1. [VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/) にアクセスし、Core コンポーネントをダウンロードします。
2. 解凍したファイルをプロジェクトルートの `voicevox_core/` フォルダに配置します。
3. 具体的なファイル一覧については、同フォルダ内の `README.md` を参照してください。
