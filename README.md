# Live2DPet Workspace — AI 桌面宠物伴侣

**[English](README.en.md)** | **[日本語](README.ja.md)** | **中文**

> 本项目的宣传名为 **Live2DPet Workspace**。可执行文件与用户数据目录仍沿用原名称 `Live2DPet` / `live2dpet`，不影响使用。

> 本项目基于 [x380kkm/Live2DPet](https://github.com/x380kkm/Live2DPet) 二次开发，遵循 MIT 许可证。

一款把 **AI 对话、日程管理、复习卡片、番茄钟、计时器、任务 Agent、云同步** 全部塞进 Live2D 桌宠的开源桌面应用。

## 核心功能

### 1. 对话与记忆

- **自然对话** — 支持所有 OpenAI 兼容 API（DeepSeek、OpenRouter、Grok、Ollama 等）
- **角色扮演** — 通过角色卡定义名字、身份、性格、称呼习惯、场景和硬性规则
- **记住你** — 自动提取「用户画像」（名字、身份、目标、偏好、背景），跨对话保留
- **观察环境** — 读取当前窗口标题、截图，让 AI 知道你在做什么
- **语音合成** — 集成 VOICEVOX，日语声线朗读（中文自动翻译成日语）
- **陪伴天数** — 从第一次启动开始计算，AI 可以自然提及「我们认识多久了」
- **普通对话记忆** — 保留最近 12 条聊天，跨天时在 prompt 中插入日期标记
- **Agent 历史摘要** — 滑动窗口 20 条 + 旧消息自动压缩为摘要

### 2. 三种对话模式

切换按钮在聊天框左侧，图标循环变化：

| 图标 | 模式 | 行为 |
| :--- | :--- | :--- |
| 💬 | 普通对话 | 日常闲聊，AI 会主动说话 |
| 🤖 | Agent 模式 | 调用工具完成任务（读写文件、管理待办、加复习卡等） |
| 📋 | 规划模式 | 先让 AI 列执行计划，你批准后才动手 |

### 3. Agent 内置工具

用自然语言说话即可调用：

**文件类（默认允许）**
- 读文件、列目录、递归列目录
- 按文件名搜索（支持 `*.js` 通配符）
- 按内容搜索（支持正则）

**任务类（默认允许）**
- 待办：添加、列出、完成、修改、删除
- 日程：添加、列出、修改、删除
- 提醒：添加、列出、删除（支持每天/每周重复）
- 复习卡片：添加、修改、列出、评分、删除、统计
- 计时器：创建倒计时/正计时、列出、暂停、继续、删除
- 番茄钟：启动多轮工作/休息循环

**敏感类（默认询问）**
- 写文件、打开 URL

每个工具的权限可在 **设置 → Agent 工具权限** 里改成 `allow`（直接执行）、`ask`（每次询问）或 `deny`（禁止）。

### 4. MCP 工具扩展

除内置工具外，可接入任何 MCP Server：
- **设置 → MCP → 点「+ 添加 Server」**
- 常见例子：`@modelcontextprotocol/server-filesystem`、`mcp-server-git`
- 支持多个 Server，同名工具自动加前缀

### 5. 日历 / 日程 / 提醒 / 待办

右键桌宠 → **工具 → 日历**：

- **月视图**，有日程的日期显示标记
- **多天日程**横跨显示为色带
- 点某天看当天**日程、待办、提醒、复习卡片**
- 在日历里直接新建/编辑/删除日程、待办、提醒
- **提醒状态**：
  - 到点触发后显示「✓ 已提醒」（划线）
  - 超过 30 分钟未触发显示「⚠️ 已错过」
- 可切换编辑复习卡片的**下次复习日期**

### 6. 复习卡片（SM-2）

右键桌宠 → **工具 → 复习卡片**：

- 卡片有正面（问题）和背面（答案），支持科目和标签
- Anki 同款 **SM-2 间隔重复算法**
- 评分四档：忘了 / 勉强 / 记得 / 太简单
- 独立窗口，支持快捷键：空格翻面、1/2/3/4 评分、ESC 关闭
- 支持编辑、删除、新建、搜索、按科目/标签筛选

### 7. 计时器 / 番茄钟 / 悬浮窗

右键桌宠 → **工具 → 倒计时 / 计时**：

**倒计时**
- 自定义名称、时长（时/分/秒）
- 快捷预设：1 分钟 / 3 分钟 / 5 分钟 / 25 分钟
- 到点播报自定义提醒语（默认值可在 **设置 → 计时默认提醒语** 修改）
- 完成后自动写入日程

**正计时**
- 无目标时长，用户手动停止
- 停止后播报「本次共用时 X 分 X 秒」
- 完成后自动写入日程

**通用操作**
- 暂停 / 继续
- 完成后「🔄 再计时」只需改时长，不重填名称
- 多个计时器并行
- 支持 `{name}` 之类的角色卡模板

**番茄钟**
- 一键启动经典 25/5 循环
- 快捷预设：25/5、50/10、90/20
- 可自定义每轮工作/休息/长休息时长、长休息间隔、总轮数
- 阶段切换自动播报，无需手动介入
- 只在**整个番茄钟结束**时写一条总结日程（不写阶段日程）

**计时悬浮窗**
- 独立透明小窗，可拖到屏幕任意位置（位置持久化）
- 显示前 3 个进行中的计时器剩余时间
- 悬停显示 **⏸ 暂停 / ▶ 继续 / × 结束** 按钮
- 无计时器时**自动隐藏**，有计时器时**自动显示**
- 用户手动关闭后不会自动重开（除非全部计时器都删掉）

### 8. 每日简报 / 周报 / 月报

**早报（默认 7:30 触发）**
- 天气、温度、紫外线指数
- 根据气温给穿衣建议，根据紫外线给防晒建议
- 今日日程、提醒、到期待办摘要

**晚报（默认 22:00 触发）**
- 今天完成了什么、还有哪些没做、明天的日程和提醒

**周报 / 月报**
- 周日 21:00 出周报，月末 21:00 出月报
- 统计待办完成率、日程数、复习次数、按科目错题率

所有简报都用角色口吻生成，不机械朗读数据。

### 9. 用户画像与观察数据

右键桌宠 → **记忆**：

- **查看 Agent 历史** — 所有 Agent 模式对话的滑动窗口 + 摘要
- **查看观察数据** — 常联系的人（按次数排序，带话题标签）、最近聊天记录（**仅记录窗口标题**）
- **用户画像** — AI 提取的关于你的长期信息（名字、身份、目标、偏好、背景），可清空重置

### 10. 云同步

设置 → **云同步**：

支持两种服务商，任选其一：

**GitHub Gist**（推荐）
- 完全免费
- 需要一个 **私有 Gist** 和一个 **Personal Access Token**（只勾 `gist` 权限）
- 通过 `https://api.github.com/gists` 读写

**坚果云 WebDAV**
- 需要坚果云账号 + **应用密码**（不是登录密码）
- 通过 `https://dav.jianguoyun.com/dav/` 读写

**功能**
- **自动同步**：数据变更 5 秒后自动上传
- **退出前 flush**：关闭程序前确保同步完成
- **启动时静默同步**：启动后 8 秒执行一次
- **冲突检测**：本地和云端都改过的文件会弹窗，让你选 **保留本地 / 保留云端 / 合并**
- **智能合并**：按 `id` + `updatedAt` 合并数组，聊天记录按时间戳去重
- **危险覆盖保护**：本地空但云端非空（或反之）时自动跳过，防止误清空
- **手动重置同步状态**：修复假冲突

同步的数据：待办、日程、提醒、复习卡片、对话记忆、Agent 历史、用户画像、观察日志、计时器、陪伴天数等。

### 11. 移动端 PWA

在 iPhone/Android 浏览器打开部署地址，即可作为独立 App 使用：

- **数据源** — 从同一个 Gist 读取
- **功能** — 查看待办、日程、复习卡片；新建/编辑/删除；卡片复习评分
- **AI 聊天** — 独立配置 API Key，注入用户画像和观察日志
- **添加到主屏幕** — iOS Safari 分享 → 添加到主屏幕，全屏运行

详见 PWA 部署章节（可选，仅需一次配置）。

## 快速上手

### 1. 配置 API

打开设置面板 → **设置** 标签页 → 填写 API 地址、密钥和模型名称。兼容所有 OpenAI 格式的 API。

推荐使用支持 Vision 的模型以获得截屏感知能力：
- 性价比：Grok 系列 / DeepSeek
- 中端：GPT-o3 / GPT-5.1
- 高质量：Gemini 3 Pro Preview

翻译 API（用于 TTS 日语翻译）：OpenRouter `x-ai/grok-4-fast`

### 2. 导入 Live2D 模型

**模型** 标签页 → 选择模型文件夹（含 `.model.json` 或 `.model3.json`）。系统会自动扫描参数、表情、动作组。

也支持图片文件夹作为角色形象。

没有模型？从 Live2D 官方示例下载免费模型。

### 3. 配置 VOICEVOX 语音合成（可选）

1. **TTS** 标签页 → 安装 VOICEVOX 组件（Core + ONNX Runtime + Open JTalk 辞書）
2. 下载 VVM 语音模型
3. 点击「保存并重启」
4. 配置 Speaker、Style 和其他语音参数

<details>
<summary>手动安装 VOICEVOX 组件</summary>

安装位置：`C:\Users\你的用户名\AppData\Roaming\live2dpet\voicevox_core`

| 组件 | 必须 | 下载链接 |
| :--- | :--- | :--- |
| VOICEVOX Core | 是 | `voicevox_core-windows-x64-0.16.3.zip` |
| ONNX Runtime (CPU) | 是 | `voicevox_onnxruntime-win-x64-1.17.3.tgz` |
| ONNX Runtime (GPU) | 否 | `voicevox_onnxruntime-win-x64-dml-1.17.3.tgz` |
| Open JTalk 辞書 | 是 | `open_jtalk_dic_utf_8-1.11.tar.gz` |
| 默认语音模型 | 是 | `0.vvm` |
| 其他语音模型 | 否 | `*.vvm` |

</details>

### 4. 自定义角色人设

**Prompt** 标签页 → 新增角色卡，编辑名称、性格、行为规则等。支持模板变量 `{{petName}}`、`{{userIdentity}}`。

### 5. 启动宠物

设置界面底部点击 **「启动宠物」**。

- 拖拽角色可移动位置
- 角色眼睛跟随鼠标（Live2D 模式）
- AI 定时截屏并通过气泡对话
- 右键桌宠打开菜单

## 数据存储

所有数据本地存储，可选择性同步到 Gist / 坚果云：

```text
C:\Users\你的用户名\AppData\Roaming\live2dpet\
├── config.json              配置（API Key、TTS 参数、云同步设置等）
├── data/
│   ├── todos.json             待办
│   ├── schedules.json         日程
│   ├── reminders.json         提醒
│   ├── flashcards.json        复习卡片
│   ├── timers.json            计时器 / 番茄钟
│   ├── chat-memory.json       普通对话记忆
│   ├── agent-history.json     Agent 对话历史
│   ├── user-profile.json      用户画像
│   ├── observations.json      观察日志
│   ├── companion.json         陪伴天数
│   ├── daily-brief.json       简报状态
│   ├── report-state.json      报告状态
│   ├── reports/               历史周报/月报
```

## 第三方许可与合规

### Live2D Cubism Core

由于 Live2D 官方许可限制，本项目**不包含** `live2dcubismcore.min.js` 和 `cubism4.min.js`。
首次从源码运行或重新克隆项目后，请自行从 [Live2D 官网](https://www.live2d.com/) 下载 SDK，将 `live2dcubismcore.min.js` 放入 `libs/` 目录。

### VOICEVOX

本项目集成 VOICEVOX，使用时请遵守 [VOICEVOX 利用规约](https://voicevox.hiroshiba.jp/term/)，并标注 `VOICEVOX: 角色名`。

**注意**：出于许可合规考虑，本仓库不包含 VOICEVOX Core 的预编译二进制文件。
请前往 [VOICEVOX 官网](https://voicevox.hiroshiba.jp/) 下载 Core 组件，解压后放入 `voicevox_core/` 文件夹。

### 其他依赖

各依赖项的许可证详见 `THIRD_PARTY_LICENSES.md`。

## 问题排查

开启控制台日志启动程序：

```bash
"你的文件夹地址\Live2DPet.exe" --enable-logging 2>&1
```

或从源码启动：

```bash
node launch.js
```

请记录出现问题时的日志输出，提交 Issue 时附上相关信息。

**常见问题**：

- **数据"消失"** — 先检查 `data/.backup/` 目录，云同步覆盖前会自动备份
- **云同步冲突** — 打开设置 → 云同步 → 点「重置同步状态」
- **MCP 工具启动失败** — 确认内置工具命令是 `{electron}`，args 是 `{mcpServer}/mcp-server.js`
- **TTS 无声** — 检查 `voicevox_core/` 目录和 VVM 模型是否完整

## 已知问题

- 关于截屏错误的 warning 请忽视，不影响正常使用
- VVM 语音模型读取错误：删除 `voicevox_core` 目录下损坏的文件后重新下载
- 开启 GPU 加速会导致读取 TTS 失败，仅使用 CPU 即可
- 长文本（>60 字）压缩朗读：VOICEVOX CPU 模式下长文本不稳定，会截断到合理长度
- 提醒超过 30 分钟未触发会自动标记「已错过」（可编辑时间重置）
- 电脑端和手机端同时编辑同一条记录可能触发冲突弹窗
